# AI副業向けポートフォリオの作り方｜初心者向けの実践ガイド

**SEO説明文**

AI副業向けポートフォリオの作り方を初心者向けに解説。架空の依頼を題材に、無料の文書作成ソフトで作品見本を作り、制作過程をまとめてPDFで共有するまでの手順を紹介します。

AIを使って副業を始めたいものの、依頼を受けた経験がなく、何を見せればよいか迷っていませんか。まず、やってみたい仕事を一つ選び、自主制作の見本を作りましょう。完成品と、どんな条件に合わせて何を工夫したかを1ページにまとめると、見る人が依頼できる内容をイメージしやすくなります。

この記事では、架空の文具店に向けた商品説明を書き、無料で使える文書作成ソフト **LibreOffice Writer** でPDFにまとめます。商品説明の案をAIで作る場合に使える指示文も用意しました。作品の整理とPDFの作成は、AIサービスを契約せずに試せます。

## 1. 見本のテーマと依頼条件を決める

初めの1件は、商品説明文1本など、完成の条件を決めやすい題材にします。Writerで新規文書を開き、最初に次の条件を書き出してください。これは練習用の設定です。

| 項目 | 練習用の条件 |
| --- | --- |
| 依頼の設定 | 架空の文具店のオンラインショップに載せる説明文 |
| 商品 | A6サイズ・無地・48ページのノート |
| 読み手 | 外出先で思いついたことをメモしたい人 |
| 成果物 | 見出し1本と、120字以内の商品説明文 |
| 使用する情報 | 表にある仕様と利用シーン。価格、紙質、耐久性、販売実績は設定しない |

仕様と利用シーンを書き分けておくと、後で文章を点検しやすくなります。「無地・48ページ」は今回の練習用の仕様で、「移動中に思いついたことを書く」は使い方の提案です。別の商品を題材にするなら、先に表の中身を差し替えます。

## 2. 制作過程と自分の工夫を記録する

### 商品説明の案を作って見直す

表を見ながら、見出しと本文を1案ずつ書きます。AIを使う場合は、[AIツール一覧](/tools/)で「文章・調査」のツールを探し、候補を絞ります。利用するサービスの料金・無料枠・入力データの取り扱い・商用利用条件を公式情報で確認します。確認できない条件は「要確認」と記録し、その条件に依存する利用は保留してください。練習には上の架空の設定を使い、依頼者の資料や個人情報の入力は避けます。

利用条件を確認できたら、次の指示文をコピーして使えます。別の商品で練習するときは、[無料プロンプト生成](/prompts/)で「商品説明」を選び、商品の仕様や読み手に合わせて指示文を作れます。

> 架空の文具店の商品ページ用に、見出しを1本と、120字以内の商品説明を1本作ってください。商品はA6サイズ・無地・48ページのノートです。読者は外出先で思いついたことをメモしたい人です。落ち着いた日本語で、用途を一つ提案してください。価格、紙質、耐久性、販売実績など、指定していない情報は加えないでください。

案ができたら、仕様を表と照らし合わせます。たとえば「インクが裏抜けしにくい」とあれば、紙の性能は設定していないため削ります。使い方が伝わるように、「メモに便利」を「移動中に思いついた案を書き留める」に置き換えます。Writerで本文だけを選択し、**ツール → 文字カウント**で120字以内に収まっているか確認します。

#### 完成見本（自主制作の練習例）

A4縦1ページにするときは、下の順に上から並べます。ページタイトルを一番大きくし、「制作条件」「完成見本」「制作メモ」の間は1行ずつ空けると、文章と制作の工夫を見分けやすくなります。

> **商品説明文の制作見本**
>
> 自主制作サンプル／架空の商品
>
> **制作条件**
>
> 外出先でメモを取りたい人に向けた、架空の文具店の商品ページ。見出し1本と120字以内の説明文を掲載。
>
> **完成見本**
>
> **移動中のひらめきを、手のひらサイズのノートに**
>
> A6サイズ・無地・48ページのノートです。移動中に思いついた案や、あとで調べたいことを自由に書き留められます。
>
> **制作メモ**
>
> 読み手に合わせ、利用場面を移動中に絞った。本文に載せる仕様は、練習用の条件表にあるサイズ・罫線の有無・ページ数に絞った。

### Writerで1ページにまとめてPDFにする

1. Writerで新規文書を開き、先頭に「商品説明文の制作見本」と入力します。その下に「自主制作サンプル／架空の商品」と明記します。
2. 「制作条件」「完成見本」「制作メモ」の順に小見出しを入れます。「制作条件」には読み手と成果物の条件、「完成見本」には見出しと本文を載せます。
3. 「制作メモ」には「読み手に合わせて利用場面を移動中に絞った」のように、自分が行った作業と判断の理由を2〜3行で書きます。AIを使った場合は、使った工程と自分で確認・修正した箇所も記録します。
4. 編集用に `portfolio-notebook.odt` として保存します。続いて **ファイル → エクスポート → PDFとしてエクスポート** を選ぶか、ツールバーのPDF出力ボタンを使い、`portfolio-notebook.pdf` として保存します。メニューの表記はバージョンや言語設定によって異なる場合があります。

## 3. 見本として表示する前に確認する

書き出したPDFを開き、できればスマートフォンでも表示します。タイトル、本文、制作メモが順に読めるか、文字がページの端で切れていないか、「自主制作サンプル」の表示がすぐ見つかるかを確認してください。共有するファイルは必要なページだけにし、文書のプロパティに残る作成者名なども確認します。

実在する企業のロゴ、第三者の画像、依頼者の情報を載せる場合は、共有前に権利と許可を確認します。今回のように文章だけで見本を作れば、画像素材を探さずに着手できます。共有リンクを使う場合は閲覧権限を設定し、一般公開ならログアウトした状態、限定共有なら許可を与えた相手のアカウントで開けるか確かめます。

まずはPDFを一人に見てもらい、「どんな仕事を頼めそうか」「どこに工夫があると感じたか」を聞きましょう。伝わりづらかった箇所を一つ直せば、最初の見本ができあがります。次に見本を増やすときは、同じ書式で、商品説明とは条件の異なる仕事を一つ選んでみてください。

次の見本を作るときは、[無料プロンプト生成](/prompts/)で「商品説明」を選び、テーマに商品の仕様、対象読者・利用シーンに想定する使い方を入力してみましょう。
