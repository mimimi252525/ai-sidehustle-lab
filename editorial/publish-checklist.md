# 記事公開前チェックリスト

- [ ] 検索意図に答える本文と具体例を編集者が用意し、既存記事と重複していないことを確認した。
- [ ] 料金・無料枠・商用利用・アフィリエイト条件は公式の一次情報で確認し、参照先と確認日を記録した。裏付けを取れない箇所は「要確認」とした。
- [ ] 機能、作業時間、収益などの主張を確認した。架空の実績や機能、根拠のない保証は記載していない。架空の教材例には例である旨を明記した。
- [ ] 引用、画像、個人情報、依頼者の資料の利用条件を確認した。
- [ ] 広告・アフィリエイトの有無を確定した。該当する場合は読者が一目で分かる「PR」または「広告」を表示し、アフィリエイトリンクの属性を確認した。
- [ ] タイトル、説明文、見出し、更新日、リンクを確認した。別の担当者がPRで本文・表示をレビューした。
- [ ] 記事が公開用データに入り、同じIDの候補を `published` にした。ビルドと型チェックを通し、プレビューで記事と一覧を確認した。
